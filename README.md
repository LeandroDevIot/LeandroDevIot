# Olá! Bem-vindo ao meu Laboratório de IoT e Sistemas Embarcados ⚡

Sou Leandro, e este espaço é dedicado exclusivamente aos meus projetos, experimentações e estudos práticos envolvendo **Internet das Coisas (IoT), microcontroladores e eletrônica**. 

Com uma base técnica em Mecatrônica e anos de vivência prática com manutenção e arquitetura de hardware, criei este perfil para documentar a ponte entre o mundo físico e o digital: a coleta de dados de sensores, automação, controle de acesso e desenvolvimento embarcado.

## 🛠️ O que você vai encontrar por aqui
*   **Sistemas Embarcados:** Lógica estruturada e desenvolvimento em C/C++ para microcontroladores (Arduino e afins).
*   **Integração de Sensores:** Coleta e processamento de dados do ambiente físico (telemetria, presença, controle de acesso via RFID, etc).
*   **Provas de Conceito (PoC):** Circuitos práticos, testes lógicos e automações documentadas desde a protoboard.
*   **Hardware de Baixo Nível:** Explorações envolvendo eletrônica digital, portas lógicas e conceitos de FPGA.

## ⚙️ Minha Stack de Hardware
*   **Linguagens e Lógica:** C, C++
*   **Plataformas:** Arduino, FPGA, Microcontroladores Diversos
*   **Design e Esquemáticos:** KiCad
*   **Conceitos:** Eletrônica Analógica/Digital, TTL, Comunicação Serial
